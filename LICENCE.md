## 🧩 About

**Overwatch 2 overlay Menu** is a curated list of Overwatch 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, overlay notes
- **Quality-of-Life Helpers** — icon catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Visual Helpers
- Player Outline — highlight teammates and enemies with colored outlines
- Health Bars — show health and shield status above players
- Ultimate Tracker — display ultimate charge for all players
- Ability Cooldowns — track enemy ability usage

### 🎨 Interface & Cosmetics
- Skin Catalog — browse skins, colors, and sprays
- Custom HUD Notes — organize interface elements
- Crosshair Editor — customize crosshair appearance

### 🏋️ Practice Layout
- Practice Range Notes — segment study on any layout
- Hero Switch Helper — quick hero selection in practice
- Ability Timer — track cooldowns in training

| Parameter | Type | Default | Description |
